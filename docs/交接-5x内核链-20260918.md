## 下一步（按顺序）

### ① 修 statfs 隐式声明（✅ 已完成并触发第 4 轮）

在 workflow 的「应用 KernelSU & SUSFS 补丁」步骤末尾（patch 之后）追加：

```bash
# 修复 ShirkNeko 5.10 补丁缺陷: statfs.c 的调用先于 extern 声明, 把声明补进 susfs.h 的 SUS_KSTAT 段
sed -i 's|void susfs_update_sus_kstat(void __user \*\*user_info);|void susfs_update_sus_kstat(void __user **user_info);\nint susfs_sus_kstat_spoof_vfs_statfs(struct inode *inode, struct kstatfs *buf, bool *is_fuse);|' ./common/include/linux/susfs.h
```

（插在 susfs.h 第 202 行 `void susfs_update_sus_kstat...` 之后，仍在 `#ifdef CONFIG_KSU_SUSFS_SUS_KSTAT` 块内，已核对插入点）
注意本地 yml 是 CRLF，Edit 脚本匹配要按坑 17 处理（python 读后探测 '\r\n'）。
